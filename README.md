# Twenty8-Production Updated Job Application

This version is based on the current public site at:
https://fats2005.github.io/twenty8-production/

Changes made:
- Removed the bottom Settings & Feedback section.
- Removed the bottom feedback interface.
- Added a settings gear icon in the upper-right corner.
- Settings drawer includes:
  - Seek for help
  - More about the company
  - Contact admin through WhatsApp (+254706756141)
  - Save changes
  - View application
  - Pending / Verified status display
  - Dark / Light theme
- Application information can be saved locally in the browser.
- After submission, the front-end status is set to Pending.
- The Verified status should only be supplied by a real recruitment backend/admin system.
- Added blurred coding-file background.

How to use:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Upload the files to the root of your GitHub Pages repository if you want to replace the current site.

Important:
This is a front-end/static GitHub Pages version. Saving data uses browser localStorage. It does not securely store CV files on a server or allow an administrator to verify applications remotely. A backend/database is required for real recruitment status and secure CV storage.
